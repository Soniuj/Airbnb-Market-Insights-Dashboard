# 🏠 Airbnb Market Insights Dashboard
This dashboard analyzes Airbnb listing performance, pricing trends, neighborhood value, room-type bookings, and review patterns to provide market insights for hosts and investors.

## 📌 Project Overview

This project presents an interactive Tableau dashboard designed to analyze Airbnb listing performance, pricing trends, booking behavior, neighborhood value, and customer review patterns.

The objective of this analysis is to identify the factors that influence Airbnb pricing and booking decisions while providing actionable insights for hosts, investors, and business stakeholders.

## 🧹 Data Cleaning & Preparation

Before importing the dataset into Tableau, the data was cleaned and validated using Microsoft Excel.

### Data Cleaning Steps

### 1. Column Validation

* Verified column names and structure.
* Ensured consistency across all fields.

### 2. Duplicate Column Check

* Compared duplicate columns using Excel formulas.
* Validated identical data using SUBSTITUTE and comparison techniques.
* Removed redundant columns.

### 3. Remove Unnecessary Columns

Deleted irrelevant columns to improve dataset quality and performance.

### 4. Duplicate Record Validation

* Checked the Listing ID column for duplicate records.
* Ensured every listing represented a unique property.

### 5. Date Formatting

Standardized date fields:

* First Review
* Host Since
* Last Review

### 6. Missing Value Handling

Handled blank values using:

* "Unknown"
* Default numeric values (1 or 2)
* Business-specific replacements

### 7. Data Error Correction

* Fixed inconsistent values.
* Corrected data entry errors.
* Standardized categorical values.

### 8. Final Validation

Performed final quality checks before loading data into Tableau.

# 📈 Business Questions Answered

### 1. Are guests mostly booking entire homes or private rooms?

**Finding:**
Entire Home/Apt listings dominate booking activity, significantly outperforming Private Rooms and Shared Rooms.

**Insight:**
Guests generally prefer privacy and convenience, leading to higher demand for entire-property accommodations.

---

### 2. Which room type receives the highest booking volume?

**Finding:**
Entire Home/Apt listings generate the highest booking count.

**Insight:**
Property owners offering complete accommodations have a competitive advantage.

---

### 3. Which property types generate premium pricing?

**Finding:**
House properties command higher average prices compared to apartments.

**Insight:**
Larger properties with more amenities tend to achieve premium pricing.

---

### 4. Which Property Type + Room Type combination has the highest price?

**Finding:**
House + Entire Home/Apt generates the highest average price.

**Insight:**
Guests are willing to pay premium rates for complete house accommodations.

---

### 5. Which host and property characteristics drive higher prices?

**Key Drivers:**

* Higher accommodation capacity
* Entire Home/Apt room type
* House property type
* Premium neighborhood location
* Strong guest ratings
* Higher review scores

---

### 6. Which neighborhoods provide the best value for money?

**Finding:**
Neighborhood value was assessed using Average Price and Average Rating.

**Insight:**
Some neighborhoods deliver comparable guest satisfaction at lower prices, providing better value for money.

---

### 7. Is there a relationship between price and reviews?

**Finding:**
Higher prices do not always result in higher review counts.

**Insight:**
Mid-range listings often receive more bookings and therefore generate more reviews.

---

### 8. How does accommodation capacity impact pricing?

**Finding:**
Listings accommodating more guests generally have higher prices.

**Insight:**
Capacity is a major contributor to pricing strategy.

---

### 9. What is the distribution of property types?

**Finding:**
Apartments represent the largest share of Airbnb listings.

**Insight:**
The Airbnb market is primarily apartment-driven.

---

### 10. Which neighborhoods have the highest average prices?

**Finding:**
Premium neighborhoods consistently achieve significantly higher average listing prices.

**Insight:**
Location remains one of the strongest drivers of Airbnb pricing.

# 🔑 Key Insights

* Entire Home/Apt listings dominate bookings.
* House properties achieve premium pricing.
* Apartments account for the majority of listings.
* Accommodation capacity strongly influences price.
* Neighborhood location significantly impacts listing value.
* High prices do not always correlate with higher review volumes.
* Guest ratings contribute to pricing performance.
